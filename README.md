# Zikeli Science Case File Archive

Interactive forensic-science case files for classroom investigation.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. After GitHub finishes publishing, open the URL shown on the Pages settings screen.

The teacher answer key is intentionally excluded from this package. Do not add it to the public repository.

## Adding another case

Create a new folder inside `cases`, give the case a unique `data-case-id`, and add its public listing to `catalog.js`. Existing cases and saved student responses remain separate.
